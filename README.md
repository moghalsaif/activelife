# Pathway health & lifestyle check-in

A modern, privacy-first web experience for the complete 75-question adult assessment in `LIFESTYLE ASSESSMENT CORRECTION EDIT.docx`.

## Open the prototype

Open `index.html` directly in a browser, or serve this folder with any static web server.

## What is included

- All 75 questions from the Preliminary Health Scan, with the women-specific source pathway shown when applicable
- The document's 3/2/1 weighted scoring method
- Strict risk overrides for the source's safety-critical categories
- The original nine-area overall-score model and critical-category safety gate
- Optional clinical detail fields for known readings and tests
- Save and resume using browser-local storage only
- Clear-data controls for shared devices and a visible fallback when browser saving is unavailable
- Miko, a question-aware guide with clear non-diagnostic boundaries
- Automated integrity checks for all 75 questions, Miko safety intents, required UI, and deployment headers
- Responsive layout, accessible controls, keyboard shortcuts, and reduced-motion support
- Print-ready result summary that can be saved as PDF

## Clinical product note

This is a wellness-screening prototype, not a medical device. The supplied document includes historical reference ranges and an older heart-attack percentage formula. That probability formula is intentionally not surfaced as a modern prediction. Clinical review, validation against current evidence, privacy/security review, and jurisdiction-specific regulatory review are required before real-world health use.
